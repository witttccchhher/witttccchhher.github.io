**WSL** - Подсистема Linux для Windows, позволяет запускать дистрибутивы линукс внутри Windows.

В этом гайде, будет описан процесс установки **NixOS** внутрь **WSL**

# Пошаговая инструкция
## Заходим по ссылке и скачивем файл nixos.wsl
https://github.com/nix-community/NixOS-WSL/releases
## Открываем командную в папке загрузок

## Запускаем команду
```sh
wsl --install --from-file nixos.wsl
```
